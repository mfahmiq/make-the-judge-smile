## How it works

`main.py` is Python 3.13 standard library only — no network, no
dependencies, fully deterministic. It writes exactly one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and asserts
the line is between 1 and 200 characters, as the bounty requires.

```sh
python3 main.py
cat /output/entry.txt
```

## The line

> My neighbour's cat, who hates everyone, chose my lap this morning and
> purred like a broken engine finally starting.

Why this line: the subject is a small good thing from today, the warmth
comes from an animal choosing trust, the surprise is that this particular
cat hates everyone, the concrete detail is the purr compared to a broken
engine starting, and the wording is fresh rather than a stock "made my
day" phrase.
